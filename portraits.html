青棠宗 · 立绘画廊（写实风格）

以下为按「性别 / 境界 / 部门」生成的真实生图立绘（写实摄影 / 电影级）。
动漫风格原版已归档至 portraits/anime/。接生图 API 后，每位仙人都可凭专属 Prompt 生成独一无二的立绘：genPrompt(c) → 生图接口 → 缓存 portraits/<id>.png → 详情页优先展示专属图。
说明：立绘外观由「基础外貌（性别 / 容貌 / 发式）＋ 当前场合着装（部位覆盖依性格 / 财力 / 场合而定，并非全身都穿）＋ 体香光晕（境界越高越清正）＋ 所在场景」共同决定。同一人换场所、换心情、突破境界后，立绘与 Prompt 随之改变。下方每张立绘下方即其生图 Prompt（可直接喂给图像接口实时重绘）。
