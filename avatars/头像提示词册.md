> **状态（2026-11-07）**：AI 文生图因积分成本已取消，**本册不含任何图片**，是随时可直接取用的完整提示词。

## 怎么用
1. **逐条取用**：复制任一人「完整 Prompt」，粘到任意文生图工具即可；本册 125 条全部齐备，按「具名核心 / 道门真君 / 他宗客卿 / 拾茧人 / 门人弟子」分组。
2. **批量出图**：读 `prompts.json`，键即人物 id，值 `prompt` 为完整英文提示词，`meta` 为中文设定。输出文件名必须是 `av-<id>.png`，放进 `avatars/` 目录。
3. **生成后启用**：把已出图的 id 填入 `avatars.js` 顶部的 `window.AVATAR_READY`，例如 `window.AVATAR_READY={"91001":1};`，对应界面会自动从旧立绘切到专属头像；未填入的 id 继续用旧立绘，可以一批一批补，不影响任何页面。
4. **统一画风**：所有 prompt 共用下方同一段风格后缀，保证 125 张并排在一起时调性一致。若换工具，只需整体替换这一段，不必逐条改。
